# Image Prediction Service

This python application is responsible for the machine-learning portion of this project.

It reads .json files generated by the image processing service & parses data into their respective modes (training/validation) and trains, and tests models with that data.

#### Environment Variables:
```
DATA_PATH {"/path/to/data.json"} (Required)
```

#### Arguments:
```
-v --Verbose (prints what is happening to stdout)
-p --Plot   (sequentially shows graphs of images in the pipeline)
-f --Filename   (choose filename)
```
